# Нейробазар — КР №3

«Интеллект продаётся, ошибки бесплатно».

**Контрольная работа №3:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».  
**Автор:** Мукаев Вильдан Рустамович  
**Группа:** ЭФБО-06-25

Версия учебного магазина нейросетей на основе КР №1, без Bootstrap. Цены вымышленные, в казахстанских тенге. Заказы и данные не отправляются.

## Страницы

- `index.html` — главная, товары, раздел о проекте.
- `catalog.html` — каталог шести нейросетей.
- `product.html` — описания и таблицы характеристик.
- `order.html` — учебная форма заявки.
- `contacts.html` — контакты и ответы на вопросы.

## Адаптивная вёрстка

На всех страницах после `css/style.css` подключён `css/responsive.css`. В нём стили написаны по принципу Mobile First с `min-width` медиазапросами для 600, 900 и 1200 пикселей. Адаптированы навигация с мобильным меню, главный блок, карточки, каталог, форма, контакты, таблицы и модальные окна. Картинки ограничены по ширине контейнера; для SVG-логотипов применяется `srcset` и `sizes`. На небольших экранах таблица прокручивается только внутри своего блока.

Предусмотрены ширины 360, 430, 768, 1024 и 1440 пикселей. Проверка этих размеров в браузере должна быть выполнена перед сдачей.

## Доступность

Сохранены семантические элементы, заголовки, подписи полей и осмысленные `alt`. Есть ссылка пропуска к содержимому, видимый фокус, мобильная навигация с клавиатуры и доступные модальные окна на основе `dialog`. Учитывается настройка уменьшения анимации.

## Lighthouse

По методичке требуется реальная проверка Accessibility в Lighthouse для `index.html`, `catalog.html` и `order.html`, с сохранением отчётов или скриншотов в `lighthouse/`. Отчёты нельзя считать готовыми до запуска аудита; показатели не выдумываются.

## Запуск

Откройте `index.html` в браузере. Зависимости и сборка не нужны.

Логотипы из [Lobe Icons](https://github.com/lobehub/lobe-icons); источники и лицензия в `images/`.

Репозиторий: https://github.com/vil-h/frontend-shop/tree/kr3-responsive

Методичка предусматривает отдельный репозиторий `kr3-responsive-shop`, но по выбранной схеме работа размещена в отдельной ветке.
