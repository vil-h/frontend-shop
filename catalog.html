Как выбирать?

Для работы с текстами пригодятся универсальные помощники. Для картинок есть отдельный инструмент, для поиска — сервис с источниками, для кода — помощник в редакторе.

Нужно ли верить ответам?

Нет, без проверки не стоит. Даже убедительно звучащие ответы могут содержать ошибки. Сверяйте важные факты с первоисточниками.
